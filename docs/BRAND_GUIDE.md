# Brand guide

## Core identity

SilentiumOS uses a shield containing a circuit-inspired eye. The intended personality is protective, focused, technical, and quiet rather than aggressive or surveillance-themed.

## Palette

- Near black: primary background
- Charcoal: panels and circuit texture
- Silver white: primary typography and shield structure
- Signal red: focus, status, and edition accents

Use red selectively. Controller focus and critical state should remain the strongest red elements on screen.

## Naming

Use **SilentiumOS — Elliot Edition** in prose and **ELLIOT EDITION** in compact visual lockups. Do not use the older generic “TV Gaming Edition” label.

## Image rules

- Keep text inside television-safe margins.
- Never add real device identifiers, accounts, addresses, or status notifications.
- Do not use commercial game art or streaming-service logos.
- Label generated device scenes as concepts.
- Do not imply affiliation with Amazon, RetroArch, libretro, console manufacturers, or game publishers.
- Preserve the original aspect ratio; do not stretch the shield or wordmark.

## Concept-image provenance

The 2026 repository hero, banner, and dashboard concept were generated specifically for SilentiumOS using the existing Silentium Labs shield assets as references. The device scene is an original visualization informed by the public Fire TV Stick HD form factor and is not copied from a retailer image.
