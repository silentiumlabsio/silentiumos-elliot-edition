# Legal Library Policy

SilentiumOS does not include ROM files in this repository.

The library workflow is intended for games that are:

- Public domain
- Open source
- Released as freeware with redistribution permission
- Homebrew distributed by the author or an authorized collection
- Personally dumped and legally usable by the device owner

The public tooling references curated homebrew collections as candidate sources. Collection membership is treated as a lead, not proof that every file is appropriate for every use. The workflow applies filename/content filters, format checks, deduplication, storage limits, and device smoke tests.

Commercial Nintendo, Sega, Sony, and other retail ROMs must not be committed, attached to releases, or distributed through this project.

Emulator cores and RetroArch binaries are also excluded and remain governed by their respective licenses.
