# Screenshot policy

## Current public images

- `dashboard-concept.png` is a generated screen-only interface concept.
- `../assets/silentiumos-elliot-hero.png` is a generated product proof-of-concept scene.

Both images contain invented state and are safe for public presentation. They are not represented as photographed device evidence.

## Before publishing a real capture

Remove, crop, or blur:

- Private IP addresses and household hostnames
- Device names, build fingerprints, and serial numbers
- MAC, Wi-Fi, and Bluetooth addresses
- Personal accounts, notifications, and avatars
- Household network names
- File-system usernames and local paths
- Production PINs or PIN entry
- ADB authorization prompts and keys
- Copyrighted ROM names, cover art, or private library manifests
- Debug logs, terminal windows, and report output

Use a legally redistributable homebrew title if game launch behavior must be shown. Review the final exported pixels, not only the source scene, before committing.
