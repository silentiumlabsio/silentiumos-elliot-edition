# Screenshots

Only sanitized screenshots should be added here.

Before committing a screenshot, remove or blur:

- Private IP addresses
- Device names and serial numbers
- MAC or Bluetooth addresses
- Personal accounts
- Household network names
- File-system usernames and local paths
- Production PINs

The current repository uses the public SilentiumOS banner, logo, and icon because no clean device screenshot was available in the uploaded project materials.
