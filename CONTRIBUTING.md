# Contributing

This is a public source-available portfolio repository maintained by Silentium Labs.

Before opening an issue or pull request:

1. Do not include commercial ROMs, BIOS files, cores, APKs, or copyrighted game assets.
2. Remove private IP addresses, device IDs, usernames, credentials, and signing material.
3. Keep Fire OS platform claims accurate: SilentiumOS runs above Fire OS and does not replace protected firmware.
4. Explain how the change was tested on Android TV or Fire TV hardware.
5. Keep child-facing navigation and parent-tool protections intact.

Submission does not grant a license to the rest of the project. Any accepted contribution must be original or legally redistributable.
