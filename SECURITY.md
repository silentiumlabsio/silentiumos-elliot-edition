# Security Policy

## Supported source snapshot

Security reports are accepted for the current public source snapshot.

## Reporting

Email **silentiumlabsio@gmail.com** with:

- A clear description of the issue
- Affected file or component
- Reproduction steps
- Expected impact
- Suggested remediation, when available

Do not publish production PINs, private IP addresses, device serials, household network details, signing material, or non-public game files in an issue.

## Public repository rules

This repository intentionally excludes:

- Production credentials and PINs
- Signing keys and certificates
- Private network addresses
- Device identifiers
- ROMs, BIOS files, emulator cores, and APK binaries
- Runtime logs and screenshots containing personal information
